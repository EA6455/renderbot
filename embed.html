How to put Astra standby on YOUR website

Step 1: Deploy backend

Upload server.py + widget.js to your server (Vercel, Render, VPS, etc). Set env:

OPENAI_API_KEY=sk-...
ASTRA_MODEL=gpt-6-astra

Run: uvicorn server:app --host 0.0.0.0 --port 8000

Step 2: Add 1 script tag to your website

Paste before </body> on any page:

<!-- Astra Standby Widget -->
<script 
  src="https://YOUR-DOMAIN.com/widget.js"
  data-api="https://YOUR-DOMAIN.com/api/chat"
  data-color="#f5c518"
  data-title="Astra • Standby"
  data-position="bottom-right">
</script>

Step 3: Customize

data-color="#f5c518"        // orb color
data-position="bottom-right" // or bottom-left
data-title="Astra • Standby"
data-api="/api/chat"        // your backend URL

Change system prompt in server.py -> system_prompt to make Astra know your business.

WordPress / Shopify

WordPress: Appearance > Theme File Editor > footer.php paste script.
Shopify: Online Store > Themes > Edit code > layout/theme.liquid paste before </body>.
React: Add to index.html or use useEffect to inject script.

Connect to XAUUSD Bot

In server.py, you can add tool:

from xauusd_bot import get_signal
if "XAUUSD" in user_msg or "gold" in user_msg:
    signal = get_signal()
    reply = f"Live XAUUSD: {signal}"
